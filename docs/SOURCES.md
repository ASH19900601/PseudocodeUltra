## 已核实并落实的区别

- 0478/2210 标识符不允许下划线；模块定义位于主程序之前；此课程范围的子程序参数最多三个。
- 0478/2210 使用 `CONSTANT Name ← Value`，AS/A2 使用 `=`；基础文件模式为 READ/WRITE，APPEND 属于 AS/A2。
- 0478/2210 的 OTHERWISE 不加冒号；AS/A2 的 OTHERWISE 加冒号。WHILE、参数括号和 BYREF/BYVAL 按方言处理。
- Insert 的 RAND 参数为 INTEGER，结果为 REAL，范围为 0（含）到参数（不含）；DAYINDEX 的星期日为 1。完整内置签名集中在 `core/builtins.ts`。
- Guide §4.1 的集合声明为有类型的 DEFINE；§10 中方法可直接调用，构造器支持 NEW/SUPER.NEW。NEW 可隐式创建有类型的对象绑定。
- AS 包含 DATE、记录、文本文件、BYREF；A2 包含枚举、指针、集合、随机文件、OOP 与递归，按考纲章节限制。
- 2027–2029 Guide 修正了示例中的 Breed 类型；项目通过选择版本保留来源信息，不把示例笔误作为额外语法。

规则来源保存在 `core/dialects.ts`、`core/builtins.ts`；语法、静态和运行时错误通过 source 元数据关联文档、版本及条款。资源限制等工程策略明确标为非官方规范。测试中的规则正反例与诊断 golden 见 `conformance/specification.test.ts`，其他边界见 `semantics.test.ts`、`edges.test.ts`。

## 明示的模糊语义策略

Cambridge 没有为所有编程语言实现细节提供唯一消歧。以下默认值作为可配置实现策略，不冒充官方规定：

| 语义         | 默认值                 | 可选值                    |
| ------------ | ---------------------- | ------------------------- |
| 负数 DIV/MOD | 商向零截断；余数 a−q×b | 商向负无穷取整            |
| 负数 INT     | 向零截断               | 向负无穷取整              |
| ROUND 中点   | 远离零                 | 偶数舍入                  |
| FOR 界限     | 开始时求值一次         | 每次迭代重新求值          |
| 逻辑求值     | 短路；NOT > AND > OR   | 完整求值；AND/OR 从左到右 |
| BOOLEAN 输出 | TRUE/FALSE             | 小写                      |
| REAL 输出    | 紧凑表示               | 保留实数标识              |
| 文件名       | 区分大小写             | 忽略大小写                |

日期使用 UTC，显示为 dd/mm/yyyy；TODAY 可注入时钟，随机数可设置种子；STEP=0、越界、空指针解引用和资源超限均报错。策略集中在 `core/policies.ts`，UI 的语言参考提供选择，原生导出保留所选策略，并有三语言运行测试。
